{% if lang == 'ru' %}DeathTG установлен на сервере? Как подключить компьютер{% else %}Installed DeathTG on a server? Connect your computer{% endif %} {% if lang == 'ru' %}

Для первого входа и QR-кода: создай SSH-туннель от компьютера к серверу. Узнай SSH-адрес у хостинга, например root@203.0.113.10, и замени им пример в команде:

ssh -N -L 64174:127.0.0.1:{{ setup_port }} root@203.0.113.10

Оставь окно PowerShell открытым, затем на этом компьютере открой http://127.0.0.1:64174/setup и сканируй QR-код приложением Telegram на телефоне. Этот туннель нужен только для первоначальной настройки.

Для постоянной веб-панели: выбери «С веб-панелью». DeathTG установит Tailscale на сервер и покажет в серверной консоли ссылку для входа. Установи Tailscale на компьютере или телефоне и войди в тот же аккаунт, затем открой ссылку из консоли и войди в этот аккаунт на сервере. Так оба устройства попадут в одну приватную сеть; код сопряжения не нужен. Открывай адрес панели https://…, который DeathTG напечатает после подключения.

{% else %}

For the first login and QR code: create an SSH tunnel from your computer to the server. Get the SSH address from your hosting provider, for example root@203.0.113.10, and replace the example in this command:

ssh -N -L 64174:127.0.0.1:{{ setup_port }} root@203.0.113.10

Keep PowerShell open, then visit http://127.0.0.1:64174/setup on this computer and scan the QR code with Telegram on your phone. This tunnel is only needed for initial setup.

For ongoing web access: choose “Web dashboard”. DeathTG installs Tailscale on the server and prints a sign-in link in the server console. Install Tailscale on your computer or phone and sign in, then open the console link and sign in to that same account on the server. Both devices will join one private network; no pairing code is needed. Open the https://… panel address printed by DeathTG after it connects.
