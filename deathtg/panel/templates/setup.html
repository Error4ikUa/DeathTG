{% if lang == 'ru' %}DeathTG установлен на сервере? Вот как открыть настройку с компьютера{% else %}Installed DeathTG on a server? Open setup from your computer{% endif %} {% if lang == 'ru' %}
  1. Узнай SSH-имя и адрес сервера у своего хостинга. Например: root@203.0.113.10.
  2. Открой PowerShell на компьютере и выполни команду ниже, заменив root@203.0.113.10 на свой адрес. Число справа оставь таким, как порт панели из консоли сервера (обычно 64174).
ssh -N -L 64174:127.0.0.1:{{ setup_port }} root@203.0.113.10

Если SSH спрашивает, подключаться ли к серверу, введи yes, затем пароль сервера. Пока команда работает, окно PowerShell не закрывай: оно держит туннель.

Открой на своём компьютере http://127.0.0.1:64174/setup. QR-код на экране компьютера отсканируй приложением Telegram на телефоне.

{% else %}
  1. Get your server's SSH username and address from your hosting provider, for example root@203.0.113.10.
  2. Open PowerShell on your computer and run the command below, replacing root@203.0.113.10 with your server address. Keep the right-hand port equal to the panel port printed in the server console (usually 64174).
ssh -N -L 64174:127.0.0.1:{{ setup_port }} root@203.0.113.10

If SSH asks whether to trust the server, type yes, then enter your server password. Keep this PowerShell window open while setting up DeathTG; it carries the connection.

On your computer, open http://127.0.0.1:64174/setup. Scan the QR code on the computer screen with the Telegram app on your phone.
