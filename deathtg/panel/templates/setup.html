{% if lang == 'ru' %}DeathTG установлен на сервере? Как подключить компьютер{% else %}Installed DeathTG on a server? Connect your computer{% endif %} {% if lang == 'ru' %}

Если DeathTG запускается на сервере: сначала установи Tailscale на основной компьютер или телефон и войди в свой аккаунт. В консоли подтверди, что устройство готово, затем открой ссылку авторизации Tailscale, которую покажет сервер, и войди в тот же аккаунт. Вернись в консоль: DeathTG проверит владельца автоматически. Если он всё ещё ждёт, нажми Y, чтобы проверить ещё раз. При регистрации Tailscale через Google используй Google при входе.

После проверки консоль покажет приватную ссылку https://…ts.net/setup?setup_token=…. Открой её на устройстве, уже подключённом к тому же аккаунту Tailscale. Для входа нужны и эта приватная сеть, и одноразовый токен; один адрес не даёт доступ.

Выбор режима: веб-режим оставляет сайт доступным только по HTTPS через Tailscale. «Только Telegram» выключает сайт и HTTPS-маршрут после QR-входа, DeathTG продолжает работать в Telegram и консоли. SSH-туннель нужен только для ручной диагностики, не для обычной установки.

{% else %}

If DeathTG runs on a server: first install Tailscale on your main computer or phone and sign in. Confirm in the server console that your device is ready, then open the Tailscale authorization link printed by the server and sign in to the same account. Return to the console; DeathTG checks the account automatically. If it is still waiting, press Y to check again. If you created the Tailscale account with Google, sign in with Google.

After the check, the console shows a private link such as https://…ts.net/setup?setup_token=…. Open it on a device already connected to the same Tailscale account. Both private network access and the one-time token are required; knowing the address alone does not grant access.

Choose a mode: Web dashboard keeps the site available only through private Tailscale HTTPS. Telegram only turns off the website and HTTPS route after QR sign-in; DeathTG continues running in Telegram and the console. An SSH tunnel is only for manual troubleshooting, not normal setup.

{% endif %}
